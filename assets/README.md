# MeshPress Test Mesh Corpus

This directory holds the 3D triangle meshes used to benchmark STRIDE and the
competing codecs (Draco, meshoptimizer, Corto, AMD DGF) reported in the
accompanying article (see the repository root `README.md` and
`docs/paper_visual_computer_v6.md`).

All meshes are stored as Wavefront OBJ (`.obj`), vertices + triangular faces
only (no normals, UVs, or materials are used by the codec). Files named
`*.obj.cache.npz` are NumPy decode caches generated by the benchmark harness;
they are derived artifacts and may be deleted and regenerated. `*.crt` files are
Corto-compressed outputs; `.ply`/`.ply.gz`/`.zip` are alternate source
containers.

## Additional meshes (not in the paper tables)

`bunny.obj`, `armadillo.obj`, `lucy.obj`, `eyeball.obj`, `torus.obj` are
auxiliary models used during development and smoke tests. `bunny`, `armadillo`,
and `lucy` originate from the Stanford 3D Scanning Repository (research/
educational use); `eyeball` and `torus` are synthetic primitives.

## Licensing note

The meshes are redistributed here solely to make the paper's results
reproducible. Each retains the license of its original source. For the Stanford
models, cite the Stanford 3D Scanning Repository
(https://graphics.stanford.edu/data/3Dscanrep/). The `tank` asset's license is
unverified; if you reuse this corpus, confirm its rights or substitute another
mesh of comparable size.

## Reproducing the benchmarks

From the repository root:

```bash
pip install -r requirements.txt
python test_final_benchmark.py    # all encoders, all models
```

See the root `README.md` for the full dependency list (CuPy + an NVIDIA GPU are
required for the CUDA decode-speed benchmarks; scikit-learn for the adaptive
patch encoders).
